7. Como actualizar cpra.db desde un CSV

Si tenes un CSV nuevo:
1. Subirlo desde Files
2. Anotar la ruta completa

Ejemplo:
   /home/cprargentina/uploads/donors_nuevo.csv

Carga incremental:

   workon cpra-venv
   cd ~/cPRArgentina
   python load_donors.py --csv "/home/cprargentina/uploads/donors_nuevo.csv" --mode append --db cpra.db

Esto:
- agrega solo donor_id nuevos
- ignora donor_id duplicados

Reconstruccion completa:

   python load_donors.py --csv "/home/cprargentina/uploads/donors_nuevo.csv" --mode rebuild --db cpra.db

Esto:
- genera un backup .bak de la base anterior
- reconstruye cpra.db desde cero

Despues de cualquier carga:
1. Ir a Web
2. Click en Reload
3. Probar /health

10. Problemas tipicos

- Problema:
  total_donors no cambia despues de subir CSV
  Solucion:
  correr load_donors.py y luego hacer Reload en Web

- Problema:
  un antigeno valido no es reconocido
  Solucion:
  revisar data/hla_validation.csv y confirmar que este en la tabla

- Problema:
  el codigo local cambio pero la web sigue igual
  Solucion:
  hacer git pull en PythonAnywhere y luego Reload

- Problema:
  /health no muestra cpra.db
  Solucion:
  revisar asgi.py y la configuracion del comando ASGI


11. Seguridad basica

- No compartir tokens
- Regenerar tokens si se exponen
- No subir CSVs reales al repositorio
- Definir aparte si cpra.db se versiona o se reconstruye al desplegar


12. Orden recomendado para actualizar sin romper

1. actualizar codigo en GitHub
2. git pull en PythonAnywhere
3. si cambian los datos, actualizar cpra.db con load_donors.py
4. Reload en Web
5. probar /health
6. probar la home
